# @boguan/catalog

## 责任

唯一维护代码管理的采集配置：公司、数据源、标签别名与关键词标签规则。数据库保存启停、水位、封禁等运行态状态。

| 文件             | 内容                                                       |
| :--------------- | :--------------------------------------------------------- |
| `companies.ts`   | 收录的公司                                                 |
| `sources.ts`     | 每个源的公司归属、适配器、列表入口、时区、语言与去重优先级 |
| `tag-aliases.ts` | 源站原始写法到规范标签的人工映射                           |
| `tag-rules.ts`   | 关键词打标规则与打分                                       |

## 技术栈

TypeScript strict，零运行时依赖。

## 约束

- 标签清单是 `tag-rules.ts` 的并集：新增标签只改这一个文件。
- 只有跑通 `vpr crawl --dry-run` 的源才能进 `sources.ts`，`enabled` 意味着每天都会被请求。
- 跨源去重按 `priority` 小者胜出，公司内的相对顺序由它表达。
- 不依赖运行时、数据库、网络或其他 Boguan 包。
- 不保存可由数据库运行态修改的状态：seed 只覆盖代码里有真相的字段。
