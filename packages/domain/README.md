# @boguan/domain

## 责任

无 I/O 的业务规则。按概念分文件，全部经包入口导出：

| 概念     | 文件              | 能力                                           |
| :------- | :---------------- | :--------------------------------------------- |
| 身份     | `identity.ts`     | URL 归一、标题归一、slug 生成、源站标签归一    |
| 时间     | `time.ts`         | 源站时间解析、按源站时区取年与自然日、时区零点 |
| 期       | `edition.ts`      | 期号与出版日互推、期的时间窗                   |
| 文本     | `text.ts`         | 实体解码、HTML 转纯文本、摘要截断              |
| 清洗     | `curate.ts`       | 标题站点后缀、非文章页判定、可见性原因         |
| 指标     | `metrics.ts`      | 阅读时长、代码标记                             |
| 索引门槛 | `indexability.ts` | 集合页进入索引的最少篇数                       |
| 标签分组 | `taxonomy.ts`     | 标签到浏览分组的映射                           |

## 技术栈

TypeScript strict、Luxon（时间解析与时区）、`entities`（HTML 实体）。没有其他运行时依赖。

## 约束

- 保持纯函数；不得访问数据库、文件系统、网络、Astro 或进程环境。
- 解析失败或无法判定时返回 `null`，不猜测、不隐式修复数据。
- 同一条规则只在这里实现一次，调用方不得复制阈值或判定逻辑。
- 不依赖其他 Boguan 包。
